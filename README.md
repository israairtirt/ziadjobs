# Ziad Jobs (زياد جوبس) — live demo

**https://israairtirt.github.io/ziadjobs/**

منصة توظيف ليبية: وظائف مع تاريخ النشر وعدد المشاهدات، تقديم مباشر عبر واتساب أو البريد، دليل الشركات، منشئ سيرة ذاتية بمساعدة الذكاء الاصطناعي، ولوحة تحكم تحدد مدة ظهور كل وظيفة وشركة من تاريخ إلى تاريخ.

An Arabic-first job board prototype for Libya: jobs with posting date and view count, apply straight to WhatsApp or email, a company directory, an AI-assisted CV builder, and a dashboard that sets how long every job and company stays online.

- Dashboard: [/ziadjobs/admin](https://israairtirt.github.io/ziadjobs/admin), password `ziad2026`
- This is the static demo build. Everything runs in your browser: the data is fictional and saved only in your browser, and the CV assistant uses the built-in helper.
- This repository holds only the built files.
